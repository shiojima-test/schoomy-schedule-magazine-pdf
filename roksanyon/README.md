# ロクサンヨン公開

ロクサンヨン（スクーミーワールド通信634）をホームページに載せる仕組み。

| 部品 | 置き場所 |
|---|---|
| アップ画面（サトエリさん用） | `gas/` を Apps Script「ロクサンヨン アップロード」に貼ってウェブアプリで公開 |
| PDFの置き場 | ドライブ「ロクサンヨン公開」 1acenOS-UcYfSbFqtKL_Nt8D8ymrmj6YU（親の共有を引き継がない） |
| 掲載一覧 | ドライブ「ロクサンヨン掲載一覧（自動・さわらない）」 1v5_TuOy0FcOQoDqXcYIV6YqHJTPburmvtccXyNBwsUc（閲覧のみ公開） |
| ホームページ | `wordpress-block.html` をカスタムHTMLブロックに貼る（一度だけ） |

流れ: アップ画面で月号を選んでPDFを送る → フォルダに `ロクサンヨン_YYYY-MM.pdf` で保存・閲覧公開 → 掲載一覧を作り直す → ホームページが一覧を読んで表示。

- 同じ月号を送ると差し替え（古いほうはゴミ箱）。取り下げもゴミ箱（ドライブから戻せる）
- 表紙はドライブのサムネイル（PDFの1ページ目）、ダウンロードはドライブの直接ダウンロード
- ページに出るのは docs.google.com / drive.google.com だけで、GitHubは出ない
- 合言葉なし（v1.1）。アップ画面のURLを知っている人だけが使える
